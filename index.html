Yes. The script expects specific column names (Client, Email, Service, Context, Status, Next Follow-Up, Follow-Up Count, Follow-Up Sent, Automation Notes) — these are documented in the setup guide. Every email is a draft — you can edit any part of it before sending. The AI is instructed to write in a warm, specific, non-salesy tone based on the Context field you provide. If results aren't matching your voice, the Setup + Support tier includes AI prompt tuning so the output matches your service type and writing style.
Yes. The default intervals are 3 days for the first follow-up, 3 days for the second, 5 days for the third. You can change these constants at the top of the script — the setup guide shows exactly which lines. The Setup + Support tier includes timing customisations as part of the package.
Yes. FollowUpFlow works with both personal Gmail accounts and Google Workspace business accounts. The Apps Script runs under whichever account is editing the sheet, and Gmail drafts are created in that account's Drafts folder. No admin permissions required beyond standard script authorisation.
